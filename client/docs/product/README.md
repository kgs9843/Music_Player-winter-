# Product

## 한 줄 요약

**노래 파일 업로드** 또는 **YouTube 링크**로 음악을 재생하면, 음악에 맞춰 **눈이 내리고 반짝이는 겨울 비주얼라이저**를 보여주는 프로젝트입니다.

## 사용자 여정 (MVP)

- **선택**
  - 프리셋 음악 버튼 선택
  - 또는 로컬 음악 파일 업로드
  - 또는 YouTube URL 붙여넣기 → “Convert & Play”
- **재생/몰입**
  - 재생이 시작되면 오버레이가 사라지고,
  - 오디오 주파수(FFT) 데이터를 기반으로 파티클(트리/바닥/스파클)과 눈 애니메이션이 반응합니다.

## 핵심 가치

- **즉시성**: 링크/파일만 넣으면 바로 겨울 분위기 연출
- **시각적 만족**: Bloom(발광) + 파티클로 “반짝임” 강화
- **확장성**: FSD 구조로 기능(오디오 소스/플레이어/비주얼) 확장을 쉽게

## 범위/의존성

- 프론트는 Vite + Three.js 기반 렌더링
- YouTube 변환은 `http://localhost:3000/extract-audio` API를 호출합니다(백엔드가 필요)
